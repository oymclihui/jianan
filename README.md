## 数据

[三类人员建安题库全集.csv](三类人员建安题库全集.csv) — 5500 题的题干、选项、答案与解析，2.1 MB，可直接导入 Excel 或自建题库。

字段：题型、章节、题干、选项 A–D、答案、解析。

## 数字速查表覆盖范围

从 5500 题中筛出答案含数字/单位的 570 题，去重合并为 **27 组、302 条**，覆盖：

- 法规时限与罚则（申请、审批、复查、延期、事故报告时限）
- 安全生产责任与费用（安全文明施工费、工伤保险、意外险）
- 人员配备与班组（专职安全员数量、班组人数、培训学时）
- 脚手架、模板、基坑、洞口临边防护尺寸
- 临时用电（JGJ/T 46-2024，漏保参数、接地电阻、线缆截面）
- 起重吊装、施工升降机、塔式起重机参数
- 消防、噪声与文明施工（昼 75 dB / 夜 55 dB）
- 安全检查评分与标准化（评分表分值、合格线）

## 关键考试规则

- 知识考核：100 分制，60 分合格
- 能力考核：50 分制，30 分合格
- 知识题库 5500 道，能力题库 1475 道

## 数据来源

陕西省住房和城乡建设厅 2026-04-09 发布的考核题库通知附件（管理.xlsx / 法律法规.xls / 技术.xls），经解析整理为 JSON、CSV 与单文件 HTML。
